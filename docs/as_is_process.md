# As-Is Process

The current process depends on manual coordination and ad hoc agent support.

```mermaid
flowchart TD
  A["Research task arrives via Email, Teams, or Excel"] --> B["Researcher or assistant agent collects details manually"]
  B --> C["Excel tracker is updated manually"]
  C --> D["Missing fields are checked manually"]
  D --> E["Supervisor approval is requested through message or email"]
  E --> F["Team waits for response without automatic reminders"]
  F --> G["Analysis or agent output is created separately"]
  G --> H["Progress report is written manually"]
  H --> I["Project status remains hard to audit"]
```

## Pain Points

- Tasks arrive through different channels and are easy to miss.
- Ownership and deadlines are not always visible.
- Approval requests are slow and hard to track.
- AI-agent outputs are not connected to formal project status.
- Reports are generated manually and may not be standardized.
