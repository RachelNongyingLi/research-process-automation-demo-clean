# Automation Opportunities

## Candidate Automations

| Opportunity | Current Issue | Automation Idea |
| --- | --- | --- |
| Task intake | Requests arrive through different channels | Use Forms or Teams trigger to create structured task records |
| Field validation | Missing owner, due date, or approval status | Run validation before creating or updating the tracker |
| Approval routing | Supervisor approval is requested manually | Use Power Automate approval action |
| Deadline tracking | Reminders depend on memory | Trigger reminders for open tasks close to due date |
| Agent output collection | Summaries are disconnected from tracker | Store agent output references next to task records |
| Weekly reporting | Reports are manually written | Generate report from task tracker and send Teams/email update |
